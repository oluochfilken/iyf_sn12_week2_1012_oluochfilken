## Author

Oluoch Filken

## Project Description

This project improves my Week 1 personal portfolio using CSS.

It demonstrates CSS fundamentals, the box model, Flexbox, CSS Grid,
responsive design, accessibility and reusable components.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Git
- GitHub
- SPCK Editor

## Features

- Four-page personal portfolio.
- Shared external CSS stylesheet.
- CSS reset and custom properties.
- Responsive navigation using Flexbox.
- Responsive project cards using CSS Grid.
- Mobile-first responsive design.
- Keyboard focus and hover states.
- Styled contact form.
- Box model practice.
- Flexbox practice.
- CSS Grid gallery.
- Magazine layout.
- Five daily CSS challenges.
- Semantic HTML demonstration.

## How to Run

1. Download or clone this repository.
2. Open the project folder in a code editor.
3. Open `index.html` in a browser.
4. Navigate through the portfolio pages.

## Responsive Design

The portfolio uses mobile-first CSS.

The project grid displays:

- One column on mobile.
- Two columns on tablet.
- Three columns on desktop.

The footer displays:

- One column on mobile.
- Two columns on tablet.
- Four columns on desktop.

## Testing

Test the website at:

- 320px
- 768px
- 1024px
- 1440px

Check that there is no unwanted horizontal scrolling.

Run Lighthouse to record actual performance, accessibility,
best practices and SEO scores.
